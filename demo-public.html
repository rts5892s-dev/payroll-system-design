군포공장 급여계산 시스템

원본 양식 분석 · 03월 급여(군포공장)(수정1).xlsx · 시트 군포 · 51개 컬럼(A~AY) · 2026-09-13

개요

원본 엑셀은 직원 1명당 51개 컬럼을 가로로 나열한 급여대장 형식이며, 시급·지급총액·공제액계·실수령액과 두 가지 검증열(시급점검, 월통상임금점검)이 수식으로 연결되어 있습니다. 아래는 이 구조를 그대로 계승하되 다수 직원·매월 반복 계산에 견디는 시스템으로 재설계한 내용입니다.

  • ●입력 vs 계산 분리 — 원본에서 실제 수식이 걸린 열은 13개뿐이고 나머지(상여금·연차수당·가불·4대보험료 등)는 담당자가 매월 직접 입력하는 값입니다. 설계는 이 경계를 그대로 존중합니다.
  • ●샘플 데이터 주의 — 원본 3행(연번 1)의 성명 값이 0으로 되어 있어 테스트용 임시 데이터로 보입니다. 실 운영 전 실제 인적사항으로 교체가 필요합니다.
  • ●근태자료 연동 예정 — 근태자료는 현재 엑셀 업로드 → 근태확정 → 급여계산 순으로 처리되며, 향후 세콤(SECOM)이 SQL 기반 DB를 구축해 근태자료를 실시간으로 전송하면 사내 근태·급여 프로그램과 연동되도록 전환될 예정입니다. 자세한 흐름은 아래 "시스템 아키텍처 제안"을 참고하세요.

데이터 모델

원본 컬럼을 4개 논리 그룹으로 재구성했습니다. 입력은 매월 담당자가 넣는 값, 계산은 수식으로 자동 산출되는 값입니다.

직원 마스터

1회 등록 후 변동 시에만 수정 (A~H열)

  • 사번 / 성명 / 성별입력
  • 부문 / 부서 / 직책입력
  • 부양가족수입력
  • 월소정근로시간 (기본 209H)입력

급여 기준정보

연봉 계약 변경 시에만 수정 (I~M열)

  • 연봉입력
  • 기본급 / 직무수당입력
  • 시급계산
  • 고정시급 / 통상임금계산

월별 근태·실적 입력

매월 갱신 (N~AK열)

  • 보전수당 / 토요수당 / 기타제수당입력
  • 연장근로 금액입력
  • 휴일근로시간 / 공제시간입력
  • 휴일근로 / 공제분 금액계산
  • 상여금(현금·현물) / 학자금 / 연차수당입력
  • 연말정산 / 사우회비 / 가불(급여·식대)입력

법정 공제 & 산출 결과

요율표 연동 필요 (AL~AY열)

  • 소득세 (간이세액표 조회)입력
  • 국민연금 / 건강보험 / 장기요양보험입력
  • 주민세 / 고용보험료계산
  • 지급총액 / 공제액계 / 실수령액계산
  • 시급확인 / 임금확인 (검증)계산

계산 로직 (원본 수식 그대로)

각 단계는 이전 단계의 결과를 참조하므로 반드시 이 순서로 계산해야 합니다. 반올림 규칙은 원본과 동일하게 10원 단위를 사용합니다.

  1. 시급 산출
    시급 = (기본급 + 직무수당) ÷ 월소정근로시간
    연봉 대신 실제 기본급 구성으로 시급을 역산합니다.
  2. 보전시간 합계
    합계 = 기본급 + 직무수당 + 보전수당
  3. 휴일근로 · 공제분 (시간 기반 자동계산)
    휴일근로 = ROUNDUP(시급 × 휴일근로시간, 10원)
    공제분 = ROUNDDOWN(시급 × 공제시간, 10원)
    유일하게 시간 입력값에서 금액을 자동 산출하는 두 항목입니다.
  4. 지급총액
    지급총액 = 합계 + 토요수당 + 기타제수당 + 연장근로 + 휴일근로 + 공제분 + 상여금(현금) + 상여금(현물) + 학자금 + 연차수당
  5. 법정 공제 자동분 산출
    주민세 = TRUNC(소득세 × 10%, 10원)
    고용보험료 = TRUNC(지급총액 × 0.9%, 10원)
    소득세·국민연금·건강보험·장기요양보험은 매년 개정되는 법정 요율표 조회값을 그대로 입력합니다.
  6. 공제액계 · 실수령액
    공제액계 = 연말정산 + 사우회비 + 가불 + 가불(식대) + 소득세 + 주민세 + 국민연금 + 건강보험 + 장기요양보험 + 고용보험료
    실수령액 = 지급총액 − 공제액계
  7. 검증: 시급점검 · 월통상임금점검
    고정시급 = 연봉 ÷ 12 ÷ 월소정근로시간 → 시급확인 = 시급 − 고정시급
    통상임금 = 연봉 ÷ 12 → 임금확인 = (기본급 + 직무수당) − 통상임금
    두 값 모두 0이어야 "기본급 구성이 연봉과 정합"함을 의미합니다. 0이 아니면 계약연봉과 기본급 입력이 어긋난 것입니다.

시스템 아키텍처 제안

엑셀의 수식 구조를 그대로 계산 엔진 규칙으로 옮기고, 근태자료 수집 경로는 계산 엔진과 분리해 나중에 교체할 수 있게 설계합니다.

⑤ 산출물

급여대장 · 개인별 급여명세서 · 검증 리포트

  • ●근태자료 수집 경로는 교체 가능한 어댑터로 분리 — 지금은 엑셀 업로드로 근태자료를 받지만, 세콤이 SQL 기반 DB를 구축하면 실시간 연동으로 전환될 예정입니다. 계산 엔진은 "확정된 근태자료"만 넘겨받으므로, 수집 경로가 바뀌어도 ②~⑤ 단계는 그대로 유지됩니다.
  • ●근태 확정은 급여계산 전 필수 게이트 — 엑셀 업로드든 세콤 실시간 연동이든, 담당자가 근태자료를 검토·확정하기 전에는 월별 급여 입력·계산으로 넘어가지 않도록 합니다.
  • ●법정요율 테이블 분리 — 소득세 간이세액표, 국민연금·건강보험·장기요양보험·고용보험 요율은 연도가 바뀌면 갱신되므로 계산 로직과 분리된 참조 테이블(연도 버전 포함)로 관리합니다.
  • ●검증 리포트 자동화 — 시급확인·임금확인이 0이 아닌 직원을 매월 계산 직후 자동으로 목록화해 담당자가 먼저 확인하도록 합니다.
  • ●엑셀 출력 유지 — 회계팀이 익숙한 현재 급여대장 레이아웃(A~AY 컬럼 순서)으로 내보내기 기능을 유지해 전환 부담을 줄입니다.

화면 구성 — 입력 3종 + 관리자 대시보드

담당자가 매월 값을 넣는 입력 화면 3종과, 계산이 끝난 뒤 전체 현황을 한눈에 보는 관리자 대시보드를 별도 화면으로 나눴습니다. 네 화면 모두 같은 데이터·계산 로직을 공유합니다.

  • ●①엑셀형 — 원본 급여대장과 동일한 컬럼 순서(A~AY)·색 구분·틀 고정을 그대로 재현해, 기존 엑셀과 나란히 대조하며 쓰기에 적합합니다.
  • ●②카드형 — 직원 1명씩 큼직한 글씨와 그룹으로 나눠 입력받아, 컬럼이 많은 화면이 낯선 담당자도 실수 없이 입력할 수 있습니다.
  • ●③근태관리 — 직원별 일별 근태(연장·야간연장·특근·휴일·공제)를 입력하고, 월 합계를 한 번에 급여 입력에 반영합니다. attendance_daily → attendance_monthly_summary 흐름을 그대로 시연합니다.
  • ●④관리자 대시보드 — 입력이 끝난 뒤 전체 인원·지급총액·부서별 현황·검증 경고를 관리자가 한 화면에서 확인합니다. 입력은 없고 조회 전용입니다.

원본 급여대장과 같은 컬럼 순서 · 색 구분 · 틀 고정을 그대로 재현한 화면입니다.

군포 직접 입력 자동 계산

예시 3행(박민수)은 기본급+직무수당이 연봉÷12보다 50,000원 많도록 일부러 어긋나게 넣은 데이터입니다 — 임금확인·시급확인 셀이 즉시 빨간색으로 표시되는지 확인해 보세요.

직원 1명씩 화면 가득 펼쳐놓고 입력·확인하는 화면입니다. 엑셀형과 동일한 데이터를 공유합니다.

직원 선택

직원별 일별 근태를 입력 → 근태 확정(급여계산 전 게이트) → 급여 입력 반영 순으로 진행합니다. 확정 전에는 급여 반영 버튼이 비활성화되고, 확정 후에는 근태 기록이 잠깁니다.

직원 선택
날짜근태구분시간(H)

이번 달 합계 (attendance_monthly_summary)

입력 화면과 같은 데이터를 관리자 관점에서 조회 전용으로 요약한 화면입니다. 이 화면에서는 값을 수정할 수 없습니다.
